# tgwrapped

Загружаете экспорт личного чата из Telegram — получаете десять карточек про вас
двоих: кто пишет больше, кто отвечает за полминуты, кто извиняется, кто оставляет
последнее слово. Карточки отправляются обратно в тот же чат.

**Файл не покидает устройство.** Всё считается в браузере: сервера, который мог бы
принять переписку, у проекта нет. Проверяется буквально — включите авиарежим и
загрузите файл, всё посчитается.

## Запуск

```
npm run dev     # http://localhost:8000
npm test        # тесты анализатора, метрик и карточек
```

Через `file://` не работает: демо-карточки грузятся через `fetch`, нужен http.

## Как устроено

Ни сборки, ни фреймворка, ни зависимостей в рантайме — в браузер уходят те же
файлы, что лежат в репозитории.

| Файл | Что делает |
|---|---|
| `app/stats.js` | `analyze(export)` → объект статистики: объём, скорость ответа, сессии, фирменные слова, медиа, рекорды |
| `app/render.js` | десять карточек 1080×1920 и правила вердикта |
| `app/share.js` | отправка: альбом, лист одной картинкой, текст, ссылка с результатом внутри адреса |
| `app/main.js` | лендинг, карусель карточек, окно отправки |
| `app/format.js` | числа, время, склонение числительных |

Единственная сторонняя библиотека — html2canvas, лежит локально, чтобы экспорт
работал офлайн.

## Разработчику

```
npm run demo -- <path/to/result.json>   # пересобрать витрину на главной
npm run og                              # пересобрать превью ссылки
npm run site -- https://ваш.домен       # адрес сайта в OG-разметке
npm run version:check                   # версия в package.json и в <meta> совпадают
```

Правила и грабли проекта — в `CLAUDE.md`, история изменений — в `CHANGELOG.md`.
