# tgwrapped — статика, без сервера и без сборки

## Файлы

| Файл | Что делает |
|---|---|
| `index.html` | два экрана — лендинг и результат — плюс шит отправки; три `<link>` и два `<script>` |
| `main.js` | переключение экранов, витрина, загрузка экспорта, карусель карточек, шит |
| `stats.js` | `analyze(export, {names})` → объект `S`: объём, скорость ответа, сессии, фирменные слова, перестрелки, медиа, ритуалы |
| `render.js` | `buildSlides(S)` → десять `[класс, html]`; `titles(S)` — правила вердикта |
| `share.js` | вывод наружу: PNG, альбом, лист, текст, ссылка |
| `format.js` | числа, время, склонение числительных |
| `fonts.css` · `site.css` · `slide.css` | шрифты (Gluten на цифрах через unicode-range, Nunito на тексте), оболочка, карточка 1080×1920 |
| `demo.json` | готовый `S` для демо-карточек. Не экспорт Telegram |
| `vendor/html2canvas.min.js` | 1.4.1, локально — экспорт PNG работает в авиарежиме |

Модули настоящие (`<script type="module">`), поэтому `stats.js` и `render.js` тестируются в Node без браузера.

## Запуск

```
npm run dev     # http://localhost:8000
npm test        # 31 тест на анализатор, метрики, карточки и форматтеры
```

Через `file://` не работает: `fetch('demo.json')` нужен http.

## Как отправить результат

Четыре пути, все — по кнопке пользователя, ничего не уходит само:

- **Альбом** — все карточки одним `navigator.share`, в Telegram уходит альбомом. ~20 с на рендер. Без Web Share (десктоп) файлы просто скачиваются.
- **Одной картинкой** — сетка в две колонки, масштаб подбирается под число карточек: при десяти это 1710×7600. Не полоса: Telegram отправляет фотографией только картинки с суммой сторон до 10 000 px, полоса ушла бы документом без превью.
- **Текстом** — отчёт в буфер, вставляется сообщением.
- **Ссылкой** — статистика упакована gzip+base64 в хеш адреса (~2,5 КБ). Открывший ссылку видит те же карточки. Единственный способ из четырёх, при котором цифры попадают на серверы Telegram, — рядом с кнопкой об этом сказано прямым текстом.

## Проверено

- 18 МБ / 34 727 сообщений — анализ ~1,4 с в Chromium
- одна карточка в PNG — ~0,7 с в активной вкладке; в фоновой браузер троттлит примерно впятеро
- ссылка на 34 727 сообщениях: 4,6 КБ JSON → 1,9 КБ gzip → 2,5 КБ адрес
- при загрузке страницы и экспорте PNG внешних запросов нет — только localhost

Не проверено: Web Share на iOS, приём альбома и листа реальным клиентом Telegram.
